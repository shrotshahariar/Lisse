Lisse 1.1 adds a softer, longer glide and a redesigned settings window.

- Choose Precise, Balanced, or Soft glide. The easing now follows elapsed time for a consistent curve across display refresh rates.
- Customize the new interface with System, Light, or Dark mode, six accents, or your own color.
- New teal Lisse icon and a sidebar for Scrolling, Applications, Appearance, and General.
- Click the menu-bar icon for a compact menu; choose Open Settings (⌘,) when you want the full window.
- Pause scrolling instantly, or use a 30-second trial that pauses automatically.
- Improved event delivery preserves the original application target and lets the normal wheel event through when smoothing cannot start.

Download **Lisse.zip**, unzip it, and move **Lisse.app** to Applications. Requires macOS 13 or later; includes Apple silicon and Intel binaries. Enable Accessibility access for the installed copy before using smoothing.

This build is ad-hoc signed and is not notarized. The automated checks cover scroll delivery, easing, and settings; the final glide still needs a hands-on mouse-wheel check, and Intel hardware has not been tested.
